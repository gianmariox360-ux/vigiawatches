# VIGIA WATCHES - sitio web listo para GitHub Pages

## Subirlo (sin instalar nada)
1. Descomprime el ZIP.
2. En github.com crea un repositorio nuevo (botón "New", nombre por ejemplo `vigia-watches`, público).
3. Pulsa "uploading an existing file" y arrastra TODO el contenido de la carpeta (incluidas las carpetas y el archivo oculto `.nojekyll`). Pulsa "Commit changes".
4. Ve a Settings > Pages > Source: "Deploy from a branch" > Branch: main / (root) > Save.
5. En 1 o 2 minutos tu web estará en https://TU-USUARIO.github.io/vigia-watches/

## Cambiar productos (todo desde la web de GitHub)
- Fotos: en la carpeta `uploads/` pulsa "Add file > Upload files" (jpg, png o webp, nombre en minúsculas con guiones).
- Datos: abre `products.json`, pulsa el lápiz, edita nombre, precio, descripción, foto (`img`) y `stock` (true o false) y pulsa "Commit changes".
La web se actualiza sola. Marcas con página propia: Casio y Poedagar.
